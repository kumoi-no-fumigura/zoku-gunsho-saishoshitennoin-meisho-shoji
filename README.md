## 作品について

後鳥羽院が最勝四天王院に御幸した折、御堂の障子絵の名所を題に、院以下の人々が詠んだ歌を、仮名の記事とともに記す。通光・定輔・定家・家隆らの名が見える。

## 本文の作り方

国立公文書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |
